Privacy Policy

Woojin Personal Assistant — effective 31 October 2026

1. Scope

Woojin Personal Assistant is a single-user, locally run automation tool. This policy covers its access to and handling of Google user data.

2. Google user data accessed

With the account owner's explicit consent through Google OAuth, the application may access:

  • Gmail — read messages, send messages, and manage labels
  • Google Calendar — read, create, and modify events
  • Google Drive, Docs, and Sheets — read, create, and edit files

Access is limited to the account that granted consent.

3. How data is used

Data is used solely to perform tasks the owner requests, such as summarizing email, scheduling events, or editing documents. No advertising, profiling, or automated decision-making about third parties is performed.

4. Storage and retention

Data is processed on the owner's own computer. OAuth credentials are stored locally in a protected file on that device. Message and document content is not retained in any external database, and temporary working files are deleted after the task completes.

5. Sharing

Google user data is never sold, rented, or shared with third parties. It is not used to train machine learning models.

6. Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

The owner may revoke access at any time at myaccount.google.com/permissions. Revocation immediately invalidates the stored credentials.
